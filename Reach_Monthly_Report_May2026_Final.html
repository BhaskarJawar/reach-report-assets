Major Projects Summary & Initiatives
SMS via Aerialink Provider – Business 12
Introduces Aerialink as a third SMS provider within the Reach platform — alongside Sinch and ECS — delivering full end-to-end SMS parity (outbound MT, inbound MO, and delivery callbacks) while shifting credential ownership to msg-app for cleaner architectural separation.

•  Client rollout requires per-client configuration — each pilot client must be switched exclusively to Aerialink (single shortcode per client constraint), with all program/notification/confirmation rows updated to the new provider ID.
•  All trigger types support message deliveries via the new provider.
Java and Spring Version Upgrades – TECH02 / TECH19
A platform modernization initiative upgrading the Reach application stacks from Java 8 → Java 17 (LTS), Spring Boot 2.x → 3.x, and Tomcat 8 → Tomcat 10 — with full Jakarta EE namespace migration — to address end-of-life runtime risks and improve long-term security and supportability.
SemaScan 2026 – IP Risk Mitigation (Open Source License Compliance)
As part of the Sema 2026 code analysis effort, high-priority IP risk findings related to open source license compliance have been identified in several code repositories. We are working on mitigation plans for any High-risk findings (GPL, AGPL, LGPL licenses) that are currently unaddressed, either in package dependencies or directly inside source files.
RCS – Fallback and Postback Changes
Improved the fallback scenario for RCS messages by making it applicable to all message types — messages will now fall back to Reach SMS confirmation LIVE templates. Also introduced real-time capture of inbound postback data for RCS messages.
PECO PON Electric Multi Flow Enhancements – Convey 04
Implemented end-to-end platform and Doxim integration configuration for 15 new PECO Electric Management notification types (seq. 2242–2256) on the PON portal, including full DB setup and all-channel template support (SMS, Email, Voice, Push, Letter), 13 new trigger file fields (C27–C39), and updated Level One integration documentation.
Test Automation – C3R-1050
Live Environment Automation — Over the past two months, we developed and established automation for the live environment, covering both UAT and PROD. This automation performs end-to-end data verification, including validation on the data warehouse (DW) side.

Core Automation — Enhanced the core automation by adding multi-language test cases and introducing RCS test cases as part of the upgrade.
